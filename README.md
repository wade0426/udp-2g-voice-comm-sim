# 2G通訊系統模擬

這是一個使用Python開發的2G通訊系統模擬器，用於實現基本的雙向語音通訊功能。系統提供了圖形用戶界面(GUI)，支持多種音頻處理和傳輸選項。

## 功能特點

### 基本功能
- 實時雙向語音通訊
- 圖形用戶界面(GUI)操作
- 支持A/B兩種設備角色
- 自動檢測並顯示本機IP地址

### 音頻處理
- 可調節量化等級（16/256/65536）
- 可配置截止頻率（1000-8000 Hz）
- 可選擇濾波器階數（2/4/6/8）
- 噪聲抑制
- 動態範圍壓縮

### 進階功能
- XOR加密保護
- FSK（頻移鍵控）調變
- 數據交錯處理
- CRC校驗碼驗證
- 自動重傳機制

## 系統要求

- Python 3.x
- 需要安裝的依賴包：
  - numpy
  - scipy
  - sounddevice
  - tkinter

## 安裝說明

1. 確保已安裝Python 3.x
2. 安裝必要的依賴包：
```bash
pip install numpy scipy sounddevice
```

## 使用說明

1. 運行程序：
```bash
python audio_ui.py
```

2. 配置選項：
   - 選擇預設配置或手動配置
   - 預設1：高音質模式（16位元量化，高截止頻率）
   - 預設2：低音質模式（4位元量化，低截止頻率）

3. 手動配置參數：
   - 量化等級：選擇16/256/65536
   - 截止頻率：設置1000-8000 Hz
   - 濾波器階數：選擇2/4/6/8
   - 可選功能：加密、FSK調變、交錯處理

4. 設備角色：
   - A設備：使用端口5000
   - B設備：使用端口5001

## 預設配置說明

### 預設1（高音質模式）
- 16位元量化（65536級）
- 較高截止頻率（4000 Hz）
- 8階濾波器
- 停用加密、FSK和交錯處理

### 預設2（低音質模式）
- 4位元量化（16級）
- 較低截止頻率（1000 Hz）
- 2階濾波器
- 啟用FSK調變

## 注意事項

1. 確保兩端使用相同的配置參數
2. 檢查防火牆設置，確保端口（5000/5001）開放
3. 確保網絡連接穩定
4. 音頻設備正常工作且正確配置

## 故障排除

1. 連接問題：
   - 檢查IP地址設置
   - 確認端口是否被占用
   - 檢查網絡連接狀態

2. 音頻問題：
   - 確認音頻設備正常工作
   - 檢查音量設置
   - 驗證採樣率配置

3. 性能問題：
   - 降低量化等級
   - 調整截止頻率
   - 減少濾波器階數
